Privacy Policy

Effective October 5, 2026

This website is a student history project about IMAX large-format film. It is for reading only. This page explains what information is and is not collected when you visit it.

What this website collects

The website itself does not collect personal information. It has no sign-up, no accounts, no forms, no comments, no advertising and no analytics or tracking code. The site’s own code does not set cookies or save anything in your browser.

Services the website relies on

  • Hosting. This website is hosted on GitHub Pages, a service run by GitHub. GitHub may keep technical records, such as visitors’ IP addresses, to run and protect the service. GitHub’s own privacy statement covers that information.
  • Fonts. The text fonts load from Google Fonts. When your browser requests them, Google receives standard technical information such as your IP address and browser type. Google’s privacy policy covers that information.

Links to other websites

The Works Cited list names articles on other websites. If you visit those websites, their own privacy policies apply.

Children’s privacy

Because the website does not collect personal information, it does not knowingly collect information from anyone, including children under 13.

Changes to this policy

If this policy changes, the new version will be posted on this page with a new effective date.
